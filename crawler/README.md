## 说明

- 目标：猫眼电影《西虹市首富》（movie_id=1212592）用户评论
- 方式：调用猫眼移动端评论接口，按 `offset` 分页，每页 15 条，累计 465 条后停止
- 反爬处理：
  - 多 UA 轮换（iPhone / Chrome / iPad）
  - 每次请求随机休眠 2.5–5 秒；触发空响应或 JSON 解析失败时休眠 4–7 秒后跳过
  - 未使用代理池、未并发压测，不对平台发起持续高频请求
- 输出字段：用户昵称、评分、评论内容、用户城市、评论时间（UTF-8 with BOM）

## 合规提示

- 采集仅用于课程学习，遵守平台 robots 与数据最小化原则
- 原始文件中的**用户昵称属于直接标识**，本仓库不公开该文件；
  分析阶段已统一做加盐 SHA-256 哈希脱敏，详见根目录 `README.md` 与 `data/README.md`

## 运行

```bash
pip install requests
python crawler/maoyan_crawler.py
```

> 若接口结构变动或触发风控，脚本会打印 `JSON解析失败` 并跳过该页，不会中断整体流程。

## 字段说明（maoyan_cleaned_senti.csv）

| 字段 | 类型 | 说明 |
|---|---|---|
| 用户ID | 字符串 | 昵称经加盐 SHA-256 哈希后截取前 10 位，前缀 `U`，不可逆 |
| 评分 | 浮点 | 5 分制，0.5 步长 |
| 评论原文_脱敏 | 字符串 | 原始评论，手机号/邮箱/链接/@/微信已替换为占位符 |
| 清洗后文本 | 字符串 | 正则化 + 乱码修复后的正文 |
| 分词结果 | 字符串 | jieba 精确模式 + 自定义词典 + 停用词过滤，空格连接 |
| 词数 | 整数 | 分词后有效词数 |
| 用户城市 | 字符串 | 缺失填「未知」 |
| 评论时间 | 日期时间 | `YYYY-MM-DD HH:MM` |
| 评分情感标签 | 类别 | 由评分派生：≥4.0 正面 / 3.0–3.9 中性 / <3.0 负面 |
| SnowNLP情感分值 | 浮点 | [0,1]，越大越正面 |
| SnowNLP极性 | 类别 | ≥0.60 正面 / ≤0.40 负面 / 其余中性 |
| NB极性 | 类别 | 朴素贝叶斯（均匀先验）全量预测结果 |
| 数据集划分 | 类别 | 训练集 / 测试集（7:3 分层，random_state=42） |
| NB测试预测 | 类别 | 仅测试集有值，用于评估 |

## 脱敏规则

| 处理对象 | 方式 | 输出 |
|---|---|---|
| 用户昵称 | 加盐 SHA-256 → 截断前 10 位 | `U` + 10 位大写十六进制 |
| 正文手机号 | 正则 `1[3-9]\d{9}` → `[手机号]` | 保留句式 |
| 正文邮箱 / URL / @提及 / 微信 | 正则替换 | `[邮箱]` / `[链接]` / `[用户]` / `[联系方式]` |
| 用户城市、评论时间 | 不脱敏（非直接标识，分析必需） | 原值 |

盐值与映射表**不落盘、不交付**，无法反推原始昵称。
